# PBL 3: LUTS pada BPH

Halaman web Lembar Tugas Mandiri PBL ke-3, Modul Ginjal dan Cairan Tubuh: definisi, epidemiologi, etiologi, dan faktor risiko LUTS.

Isi halaman:
- Animasi 2:40 yang diputar mengikuti gulir (GSAP ScrollTrigger).
- Mindmap LUTS dengan kaitan ke kasus Pemicu 3.
- Daftar referensi.

Video di folder `video/` adalah video asli 1920x1080 yang dipotong menjadi tiga bagian tanpa encode ulang, jadi kualitasnya sama dengan aslinya.

Buka lewat GitHub Pages atau server lokal (misalnya `python3 -m http.server`); video di-stream dengan HTTP Range.
